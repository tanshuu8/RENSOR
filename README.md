# RENSOR

Digital Design & Development Studio website.

## Overview

RENOSOR designs and develops premium websites, digital experiences, and brand identities for businesses, startups, brands, and creators.

## Features

- **Selected Concepts**: Showcase of self-initiated concept projects (NOIR, ARC, PULSE)
- **Fluid Responsive Layout**: Tailored for mobile, tablet, and desktop viewports
- **Smooth Smooth Scroll & Page Transitions**: Powered by Lenis and Framer Motion
- **Contact & Inquiry Form**: Integrated with serverless API

## Tech Stack

- **React 18** + **Vite**
- **React Router v6**
- **Framer Motion**
- **Lenis Smooth Scroll**
- **Vanilla CSS (Design Tokens)**

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
